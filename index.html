Download

Because this GDPS is on GD version 1.4, you CANNOT use GDPS Switcher. This version was released before the accounts system was implemented. Instead, follow the instructions below.

  1. Download and install BlueStacks or any trusted Android emulator.
    For whatever reason, LDPlayer does NOT work.

  2. You can skip this step if you are not using BlueStacks.
    Go into BlueStacks' settings, and setup these recommended settings.
    • Performance → Enable high frame rate | Enable this.
    • Performance → Frame rate | Set this to as high as you'd like. 240 FPS is recommended.
    • Preferences → Platform → Automatically install games picked for you when you're idle | Disable this.
    • Preferences → Platform → Create desktop shortcuts for apps after installation | Disable this.
    • Preferences → Platform → Ask for sign in with Google Play upon launching a game | Disable this.
    • Preferences → Platform → Allow BlueStacks to show Ads during gameplay | Disable this.
    • Preferences → Platform → Show featured banner on start | Disable this.
    • Preferences → Platform → Open BlueStacks store on start | Disable this.
    • Preferences → Platform → Enable AI Highlights | Disable this.
    • Preferences → ESC key behaviour → Exit fullscreen | Disable this.
    • Advanced → Input debugging → Show visual feedback for taps | Enable this.

  3. Download the ClutterGDPS APK and install it in your BlueStacks app. This can either be done by dragging and dropping the APK into BlueStacks' window, or press Ctrl+Shift+B and select the APK from there.

  4. You can skip this step if you are not using BlueStacks.
    Import our keybinds file. First, download either the normal version or the version with a keybind for playtesting.
    Then, click the keyboard icon on BlueStacks' sidebar, and click "Controls editor". Then, beside "Control scheme", click the button with a downward pointing arrow, and choose the .cfg file. Finally, click "Save", and exit out of that menu.
